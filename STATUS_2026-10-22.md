### 1.2 Bugs found by repeated runs (all fixed, commits ebf709e / 21f9ade)
1. Strict audit silently off on real data: `linking_audit` / `hull_locate` / AIR_DRILL read the GT `.obj` for the
   hull grid frame; on real captures the load failed inside a try/except, so the RANK gate, the air-loop drill and
   `[STRICT]` never ran. Symptom: a count-rescue drill of 1.6 edges in a corner of the handle membrane counted as
   genus 1 (kettle 1/4–2/4 runs, mug 1/3). Fix: plug cache stores `lo/hi`; real plug cache from the RealScene hull;
   `RESCUE_RANK` (real data): rescue-only handles must raise the linking rank. After: kettle 4/4, mug 4/4.
2. Stage 5b / 6b crumple real surfaces (dihedral 18 → 50°, 6b again 47°): the late-pass DR rounds and the bare seam
   refit have no adaptive remesh / collapse / PALF Laplacian; only runs that enter 5b were hit. Fix: on REAL_DATA 6b
   uses the Stage-6 PALF settings (500 steps). After: no crumpled run in 22+.
3. Lens distortion ignored: `real_scene` projected with a pinhole while COLMAP's SIMPLE_RADIAL k1 = −0.015…−0.039
   moves silhouettes 2–5 px median / 8–20 px p95. `real/undistort_scene.py` → `<obj>_ud` (SIMPLE_PINHOLE). Not the
   cause of the ridges (see 1.4), fixed anyway.
4. `REFINE_GUARD=0.05`: Stage-6 refine diverged on the tripod (ho16 0.959 → 0.016); the input mesh is kept.
5. Non-determinism: `SEED` only seeds torch/numpy and the chain draws no random numbers; two Stage-1 runs with the
   same seed differ by up to 0.175 (GPU accumulation order). Hence success RATES over repeated runs, never "seed 0".

### 1.3 Surface quality experiments (kettle, mug, bottle, fish)
| experiment | result |
|---|---|
| Taubin on the final mesh, 5/15/30/60 iters | grain removed (dihedral 7.1 → 2.8° at 15), ridges stay, IoU −0.0016 |
| exact silhouettes of a smooth mesh through the same 151 cameras (`real/make_syn_scene.py`) | NO ridges → the chain is fine, the real silhouettes are inconsistent |
| + 2 px random per-frame shift | still none (sub-pixel at 512) |
| + 6 px random shift | whole surface crumples → few-pixel inter-view inconsistency is enough; real ridges are oriented = structured error (handle-hole frames f_072–081, reflective table edge) |
| RoMa poses instead of SIFT | ridges unchanged (IoU 0.983 vs 0.982) — not poses |
| undistorted scene | unchanged — not distortion |
| stronger PALF Laplacian ×2.5 / ×5, soft silhouettes SIL_BLUR 2/3 | not removed; SIL_BLUR=2 once crumpled (1 sample) |
| MoGe-2 mono normals, per-pixel L1 (W_NORMAL 0.03–0.3, truncated at 40°) | kettle front ridges gone BUT horizontal terraces on bottle/fish bodies, IoU −0.013 (ablation: terraces come from the normal term; a terraced mesh scores a LOWER normal error) → OFF |
| **Depth Anything V2 depth-GRADIENT prior (W_DGRAD_REFINE=0.3, scale-shift aligned, 2 scales, refine stages only)** | kettle 6.9 → 3.2°, bottle 10.5 → 4.0°, fish 10.1 → 9.3°, mug 7–10 → 6.9°; IoU unchanged; handles kept; no terraces → **default** |
Metric lesson: held-out silhouette IoU does not see surface quality (crumpled runs had the HIGHEST IoU); normal error
is fooled by terraces; report IoU + dihedral mean + MoGe-normal error + renders.

### 1.4 Known limits
Mug opening is a cap (silhouettes cannot see the cavity; the normal prior fights it); tripod true genus unverified;
headphones capture unusable (oracle unstable: folded headband, top-down views); only genus ≤ 1 real objects so far — a
genus ≥ 2 real capture is the next data need. Thingi10K must be re-run before RESCUE_RANK goes on for synthetic data.

## 3. Paper position after this week
Image-based, closed-by-construction, per-handle verified topology with an oracle that refuses unstable cases:
71/96 strict on Thingi10K and 20/21 strict runs on five real objects, vs. methods that either keep the surface but
not the topology (RsR, DMesh++) or close it with uncontrolled genus (SAP, NeuS pending). Surface distance is where
we lose (0.0126 vs 0.007–0.008) and must be stated plainly.
